Your task is to parse a natural language description into a program that locates a target object in a 3D room.

## STRICT OUTPUT RULES
1. Output ONLY the program lines. No explanation, no comments, no markdown.
2. Every program MUST start with BOX0=LOC(...) and end with TARGET=... (or BOX0=LOC(...) alone if the object is unique).
3. ALL variables used in function arguments MUST be defined earlier as BOX0, BOX1, BOX2, ... or CENTER.
4. NEVER use undefined variable names like SOFA, DESK, TABLE. Always assign them first: BOX1=LOC(object='sofa').
5. The object= argument in LOC() MUST include ALL descriptive attributes from the description (color, material, shape, etc.).
6. Do NOT create new functions. Use only the provided ones.
7. Do NOT split a single object into multiple LOC() calls based on its material or parts.

## AVAILABLE FUNCTIONS
LOC(object)              → locate all instances of an object by description
LEFT(targets, anchors)   → targets to the left of anchors
RIGHT(targets, anchors)  → targets to the right of anchors
FRONT(targets, anchors)  → targets in front of anchors
BEHIND(targets, anchors) → targets behind anchors
HIGHER(targets, anchors) → targets above anchors
LOWER(targets, anchors)  → targets below anchors
HIGHEST(targets)         → topmost target
LOWEST(targets)          → bottommost target
CLOSEST(targets, anchors)→ target nearest to anchors
FARTHEST(targets, anchors)→ target farthest from anchors
BETWEEN(targets, anchors)→ target between two anchors
MID(targets)             → middle target in a group
CALC_SIZE(targets)       → returns sizes of targets
MIN(data)                → object with minimum size/value
MAX(data)                → object with maximum size/value
CENTER                   → center of the room (pre-defined variable, do NOT assign it)

## COMMON MISTAKES TO AVOID

WRONG — undefined variable in anchors:
BOX0=LOC(object='chair')
TARGET=CLOSEST(targets=BOX0, anchors=SOFA)   ← SOFA is never defined!

CORRECT:
BOX0=LOC(object='chair')
BOX1=LOC(object='sofa')
TARGET=CLOSEST(targets=BOX0, anchors=BOX1)

WRONG — splitting one object into multiple LOC calls:
BOX0=LOC(object='chair')
BOX0=LOC(object='plastic')       ← overwriting BOX0, and 'plastic' is not an object
BOX0=LOC(object='metal legs')    ← 'metal legs' is not an object

CORRECT — include all attributes in one LOC:
BOX0=LOC(object='plastic chair with metal legs and thin arm rests')

WRONG — missing TARGET line:
BOX0=LOC(object='brown coffee table')   ← no TARGET assigned

CORRECT:
BOX0=LOC(object='brown coffee table')
BOX1=LOC(object='chair')
TARGET=FRONT(targets=BOX0, anchors=BOX1)

WRONG — program does not end with TARGET:
BOX0=LOC(object='window')
BOX2=LEFT(targets=BOX0)   ← result stored in BOX2, not TARGET

CORRECT:
BOX0=LOC(object='window')
TARGET=LEFT(targets=BOX0)
